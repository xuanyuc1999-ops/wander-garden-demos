# 漫野田园原版 v0.9.1 完整工程

Godot 4.7.2 打开 project.godot，首次导入后按 F5；默认启动完整美术入口 play_meadow.tscn。
原先工作目录默认入口仍指向早期灰盒，本上传副本只修正启动与可移植导出配置，游戏脚本和资源保留 v0.9.1。

五区种植、宠物陪伴、通道、背包、图鉴和程序化外围；角色采用真实 Lux Idle/Walk/Jog/Water/Interact 预设。
步行1.8m/s、Shift慢跑5.4m/s，含v0.9.1腿部/刹停与星谷树、水面修正。

WASD移动，右键拖动视角，F开垦，E播种/浇水/收获/互动，Q换种子，B背包，J图鉴，T调整生长速度。
美术运行时组装，编辑器未运行的画面不代表最终场景。

包含运行模型、完整分辨率贴图、原始GLB、Blender源文件、脚本、音频、字体和参考图。
未包含可重建Godot缓存、私有云回执、密钥及其他版本的临时下载；同内容下载副本和辅助下载ZIP不重复归档。
Windows/Web完整可运行包在上一级builds目录。独立工程验证见仓库docs。
