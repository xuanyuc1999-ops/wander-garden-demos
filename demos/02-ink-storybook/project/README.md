# 漫野田园 · 墨线赛璐璐童话版

2026-10-26 可玩美术候选，Ink Cel Storybook。五区、种植、宠物和程序化外围已接入新风格；美术仍待用户体验确认。

## 风格与制作范围

深靛墨线、分层明暗、青绿草地、珊瑚屋顶、金色道路与紫蓝星谷，形成更明显的插画感。原版 v0.9.1 及被放弃扩产的淡彩试样另行保留。

本版通过 Lux3D 国内 OpenAPI 对 30 件既有资产实际生成新材质，覆盖树木、建筑、道具、植被、作物、五宠、角色及秋谷/星谷地面。清单及真实任务号见 `art/edition/ink-manifest.json`，原始返回模型见 `art/assets/raw/lux-ink-*`，实际输入参考图见 `art/references/ink/`。

几何和布局继承既有版本；本次不是重新生成全部网格。描边、赛璐璐光照、天空、水面及场景配色由本地 Godot 实现。Lux 输出不保留动画的部分，将新材质接回原模型；萤火虫兽通过逐三角形匹配与 UV 接缝拆分保留原骨骼、动画、位置及权重。没有用静态云模型替换动态角色。

本次 30 × 19 = 570 Lux 报价积分。此前淡彩三试样 57 积分、历史 Lux 439 积分分别保留记录，Lux 累计报价承诺 1066；这些是报价/提交记录，不是重新查询的账户结算余额。Meshy 费用属于另一钱包。

## 启动

- Windows：解压 Windows 包，保持 `WanderGarden.exe` 与 `WanderGarden.pck` 同目录，运行 EXE。
- 源工程：Godot 4.7.2 打开 `project.godot`，首次导入后按 F5；默认入口 `play_meadow.tscn`。完整美术在运行时组装。
- Web：通过 HTTP 静态服务器提供 Web 包，例如在 web 目录运行 `python -m http.server 8781 --bind 127.0.0.1`，然后打开本机该端口。不能直接双击 HTML。无需连接生成 API。
- 再次导出前安装匹配的 Godot 导出模板；导出配置没有本机模板绝对路径。
- Web 使用最多 1024 像素纹理派生版本；独立源码保留完整分辨率资源。

## 操作


| 按键 | 操作 |
|---|---|
| WASD / Shift | 移动 / 轻跑 |
| 按住鼠标右键拖动 / 滚轮 | 环绕视角 / 拉近拉远 |
| F | 在前方平地开垦 |
| E | 对最近目标播种、浇水、收获、投喂、采集或开门 |
| Q | 切换有库存的种子 |
| G / T | 自由与网格开垦 / 三档生长速度 |
| L | 对当前地块松土，加速 20% |
| R | 让同伴原地休息，或邀请附近的已结交宠物 |
| B / J | 行囊 / 图鉴 |
| P / V / Enter | 拍照模式 / 滤镜 / 保存照片 |
| M / H | 音乐开关 / 操作提示开关 |
| Esc / F5 | 暂停或关闭面板 / 手动保存 |

正常速度 35 秒，快档 12 秒，慢档 65 秒。播种后再按 E 浇水。未浇水只暂停生长；没有枯萎、饥饿、债务或离线损失。

每次收获产出 3 份作物和 2 颗种子。动物每次投喂增加 50 好感，100 后自愿跟随。同一时间只有一只跟随伙伴。每条新通道需要前一区作物 2 份；完成两次收获足够投喂与开门。


## 存档、性能与边界

角色步行 1.8 m/s、Shift 慢跑 5.4 m/s，沿用已有 Lux 步行/慢跑动作和 v0.9.1 刹停、腿部修正。

本版使用独立应用名“漫野田园 · Ink Storybook”。桌面存档位于 `%APPDATA%/Godot/app_userdata/漫野田园 · Ink Storybook/`；与原版进度分开。浏览器按站点保存，清除站点数据会清除其存档。

核心路径、种植区、宠物点及入口稳定；外围以 32m 区块、附近 3×3 加载，植被与采集点程序化补充。地块和进度独立持久化，不因区块卸载丢失。

这是五区可玩 Demo，未添加完整自由建造、交易、多宠同时跟随或多人联机。人物/物体轮廓仍继承原版，改变重点为材质与渲染语言。星谷更深、墨线细节更多，可通过实机体验继续评审。

原生与独立源工程均完成 120 项输入流程检查，资源风格检查 91 项；浏览器完成加载、移动/Shift、开垦播种浇水收获、背包及刷新复查。详情见随附 TEST-RESULTS.md。RTX 3080 开发机 1080p 短时测量约 60 FPS；未证明所有机器或所有浏览器都能达到此性能。
