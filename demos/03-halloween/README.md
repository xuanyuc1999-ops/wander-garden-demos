# 万圣节 · 南瓜月夜

- [完整 Godot 工程](project/)：模型、贴图、骨骼动画、脚本、音频和字体均在目录中。
- [Windows 完整试玩包](builds/Windows.zip)：下载实际 LFS 文件并解压，EXE/PCK 保持同目录。
- [Web 完整包](builds/Web.zip)：下载解压后通过 HTTP 静态服务器运行。

此目录使用 Git LFS，克隆后执行 `git lfs pull`，不要把小型 LFS 指针文件当作游戏包。
各版本的工程相互独立。首次使用 Godot 4.7.2 导入后 F5 启动，完整美术在运行时组装。
