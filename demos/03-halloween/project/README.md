# 漫野田园 · 南瓜月夜

Halloween / Pumpkin Moonlight，2026-10-26。五区完整可玩万圣节美术候选，保留原版及墨线童话版。用户美术验收待定。

## 场景与角色

- 南瓜田园谷地：橙色树冠、紫褐草甸、巫师帽小屋、南瓜灯。
- 幽雾苔藓森林：紫色树木、冷雾、薄荷小幽灵和魔法锅。
- 月镜盐湖滩：银蓝灰地表、月光水色、糖果与南瓜点景。
- 南瓜枫红秋谷：橙红枫林、新地面材质、暖色节庆通道。
- 幽光星花谷：紫色树木与地表、月光花海、发光祭坛和幽灵。

主角是新制作的奶油色可爱小骷髅，配紫围巾和南瓜挎包。几何由 Blender 本地制作，绑定既有 Lux 52 骨骼，保留五套真实 Lux Idle/Walk/Jog/Water/Interact 动作。步行 1.8m/s，Shift 慢跑 5.4m/s，沿用已有腿部和刹停修正。

本轮实际 Lux3D 国内生成：4 件图生模型（南瓜灯、幽灵、魔法锅、糖果篮）+ 8 件场景材质（四类树、小屋、祭坛、秋谷/星谷地面）。实际任务号与资源 SHA256 见 `art/edition/halloween-manifest.json`；原返回模型在 `art/assets/raw/`，真实输入参考在 `art/references/halloween/`。

天空、月亮、地表配色、水色、灯光、巫师帽屋顶、彩旗与蝙蝠为本地 Godot 制作。材质生成保留原场景几何，地形布局、碰撞和主路径没有重构。节庆摆件在新田地附近自动隐藏，避免挡住作物。

本版 Lux 报价承诺 4 + 152 = 156 积分；同项目 Lux 累计报价承诺 1222 积分。此数为提交报价记录，非新查询的账户结算余额；历史 Meshy 钱包另计。

## 启动

- Windows：解压 Windows 包，EXE 和 PCK 保持同目录，双击 `WanderGarden.exe`。
- 源工程：Godot 4.7.2 打开 `project.godot`，首次导入后 F5。完整美术在运行时装配，默认入口为 `play_meadow.tscn`。
- Web：使用 HTTP 静态服务器提供 web 文件夹，例如 `python -m http.server 8782 --bind 127.0.0.1`；不能直接双击 HTML。运行游戏无需 Lux API 或任何生成凭证。
- 导出配置是可移植的；在另一台电脑导出前安装匹配的 Godot 模板。
- Web 纹理使用最多 1024 像素的派生版本；完整源码保留原生分辨率和新骷髅/道具参考的 Blender 工作文件。

## 操作



| 按键 | 操作 |
|---|---|
| WASD / Shift | 移动 / 轻跑 |
| 按住鼠标右键拖动 / 滚轮 | 环绕视角 / 拉近拉远 |
| F | 在前方平地开垦 |
| E | 对最近目标播种、浇水、收获、投喂、采集或开门 |
| Q | 切换有库存的种子 |
| G / T | 自由与网格开垦 / 三档生长速度 |
| L | 对当前地块松土，加速 20% |
| R | 让同伴原地休息，或邀请附近的已结交宠物 |
| B / J | 行囊 / 图鉴 |
| P / V / Enter | 拍照模式 / 滤镜 / 保存照片 |
| M / H | 音乐开关 / 操作提示开关 |
| Esc / F5 | 暂停或关闭面板 / 手动保存 |

正常速度 35 秒，快档 12 秒，慢档 65 秒。播种后再按 E 浇水。未浇水只暂停生长；没有枯萎、饥饿、债务或离线损失。

每次收获产出 3 份作物和 2 颗种子。动物每次投喂增加 50 好感，100 后自愿跟随。同一时间只有一只跟随伙伴。每条新通道需要前一区作物 2 份；完成两次收获足够投喂与开门。



## 存档和范围

本版应用名为“漫野田园 · 南瓜月夜”，桌面使用独立 Godot 用户目录，与其他版本进度分开。文件名 `wander-garden-halloween-v11.json`；浏览器按当前站点保存。自动保存及手动 F5 均保留。

核心玩法包括五区种植、五宠陪伴、四道通道、物品背包与图鉴、温和昼夜、星谷永夜、拍照和 32m / 3×3 程序化外围。固定种植区与地形不因装饰生成变化。没有失败惩罚。

这是可试玩 Demo；没有加入完整自由建造、复杂交易、多宠同时跟随或多人联机。节庆摆件是视觉装饰，不是新增强制任务。拍照仍按当前渲染分辨率保存。

技术与实机验证范围见交付根目录的 `TEST-RESULTS.md`。有限设备测试不构成所有 PC 或浏览器的帧率保证。
